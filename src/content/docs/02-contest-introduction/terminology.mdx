## 标准缩写

| 缩写 | 全称 | 中文 | 简要说明 |
|------|------|------|----------|
| ACM | Association for Computing Machinery | （美国）计算机协会 | 国际计算机领域最悠久的专业组织之一，早期 ICPC 以"ACM-ICPC"冠名，华语社区常将"ACM"作为 ICPC 的口语简称 |
| ICPC | International Collegiate Programming Contest | 国际大学生程序设计竞赛 | 面向在校本科生的团队式编程竞赛，三人一队共用一台电脑，五小时内解题，被视为大学阶段最高级别赛事 |
| CCPC | China Collegiate Programming Contest | 中国大学生程序设计竞赛 | 由中国高校计算机教育研究会主办，国内规模最大的大学生程序设计赛事，赛制与 ICPC 相似 |
| XCPC | — | ICPC 与 CCPC 的统称 | 日常训练和参赛语境中的常用简称 |
| OJ | Online Judge | 在线评测系统 | 自动化评测平台，用于接收、编译、运行代码并给出判题结果，是算法竞赛的核心基础设施 |
| CF | Codeforces | — | 俄罗斯团队运营的在线竞赛平台，以 Rating 体系闻名，是全球最活跃的算法竞赛社区之一 |
| NOI | National Olympiad in Informatics | 全国青少年信息学奥林匹克竞赛 | 中国国内最高水平的青少年信息学竞赛，由 CCF 主办 |
| IOI | International Olympiad in Informatics | 国际信息学奥林匹克竞赛 | 面向全球中学生的信息学竞赛 |
| IDE | Integrated Development Environment | 集成开发环境 | 提供代码编辑、编译、调试等功能的开发工具（如 VS Code、CLion） |

## 判题结果（OJ 反馈）

| 缩写 | 全称 | 含义 | 常见原因 |
|------|------|------|----------|
| AC | Accepted | 通过 | 代码正确，通过全部测试点 |
| WA | Wrong Answer | 答案错误 | 逻辑错误、边界条件未处理、输出格式不符 |
| TLE | Time Limit Exceeded | 超时 | 算法复杂度过高、死循环、未优化输入输出 |
| MLE | Memory Limit Exceeded | 超内存 | 数组过大、递归过深、未释放内存 |
| RE | Runtime Error | 运行时错误 | 数组越界、除以零、空指针、栈溢出 |
| CE | Compile Error | 编译错误 | 语法错误、缺少头文件、变量未定义 |
| PE | Presentation Error | 格式错误 | 输出内容正确但格式不符（如多余空格/换行） |

## 圈内黑话

> 以下为算法竞赛社区常用的口头表达，了解这些有助于融入竞赛氛围。

| 黑话 | 含义 |
|------|------|
| ap | "A 批"，泛指打算法竞赛的选手 |
| AK | All Killed，全场所有题目全部通过 |
| 封榜 | 比赛结束前约一小时冻结排行榜，不再显示后续提交结果 |
| 滚榜 | 比赛结束后的颁奖典礼环节，从后向前依次揭晓最终排名，营造悬念 |
| vp | Virtual Participation，虚拟参赛，即参加已结束的比赛（如打历年真题） |
| 对拍 | 用随机数据同时运行正确但暴力的程序与待验证程序，比较输出是否一致，用于验证正确性 |
| hack | 在 Codeforces 等平台上，选手可构造测试数据使他人已通过的错误代码失效 |
| FST | Failed System Test，Codeforces 赛时仅测部分数据，赛后测全部数据时失败 |
| SPJ | Special Judge，特殊评测程序，允许多种正确输出格式 |
| rp++ | 人品加一，赛前互相祝福用语 |
| tql | "太强了"的简写 |
| orz / or2 | 跪拜状表情，表示认输/佩服（or2 的"屁股更翘"） |
| % / 膜 | "膜拜"的简写 |
| n+1 / n+2 | 自己做出 n 题，某人比自己多做 1-2 题 |
| 吧唧 | 源自 badge，以 QQ 头像为样式的徽章，赛场面基时交换的纪念品 |
| 火车头 | 指代码开头极长的头文件和 #define / typedef 集合 |
| 榜歪了 | 强队意外快速做出难题，导致其他队伍误判题目难度而浪费时间 |
