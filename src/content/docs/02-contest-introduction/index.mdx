## 竞赛赛制

算法竞赛根据评分规则和提交机制的不同，主要分为三大赛制。理解赛制差异是制定比赛策略的基础。

### OI 赛制

**核心特点**：部分得分、赛后排名、无罚时。

| 维度 | 规则说明 |
|------|----------|
| 提交机制 | 通常仅允许提交一次（或有限次数），以最后一次提交为准 |
| 得分机制 | **部分分制**：即使未完全通过所有测试点，也可根据通过的测试点比例获得相应分数（如满分 100 分，通过小规模数据得 20 分） |
| 排名机制 | 比赛过程中**不显示实时排名**，赛后统一公布，按总得分降序排列 |
| 罚时规则 | 无罚时概念 |

**典型赛事**：CSP-J/S、NOIP、NOI、蓝桥杯等。

### ICPC 赛制（ACM 赛制）

**核心特点**：全有或全无、实时排名、罚时惩罚。

| 维度 | 规则说明 |
|------|----------|
| 提交机制 | 允许多次提交，但一旦某题通过（AC），后续提交不再计入 |
| 得分机制 | **全有或全无**：每题要么满分，要么零分，不存在部分分 |
| 排名机制 | 比赛期间提供**实时排行榜**，先按解题数降序，同题数按罚时升序 |
| 罚时规则 | 每题罚时 = 首次 AC 时间 + 20 分钟 × 首次 AC 前的错误提交次数；总罚时为所有已解题罚时之和 |

**典型赛事**：ICPC 区域赛/全球总决赛、CCPC 分站赛/总决赛、各省省赛、邀请赛、百度之星等。

所有现场赛（XCPC 系列）均采用 ICPC 赛制，训练时需重点适应。

### IOI 赛制

**核心特点**：部分得分、多次提交、无罚时。

| 维度 | 规则说明 |
|------|----------|
| 提交机制 | 允许多次提交（通常有次数上限，如每题 10 次） |
| 得分机制 | **部分分制**，根据通过的测试点获得相应分数 |
| 排名机制 | 比赛过程中不显示完整排名，以最后一次提交（或历史最高分）为准 |
| 罚时规则 | **无罚时**惩罚 |

**典型赛事**：IOI 国际信息学奥林匹克、团体程序设计天梯赛（GPLT）、睿抗编程赛项等。

### 赛制对比速查

| 特征 | OI 赛制 | ICPC 赛制 | IOI 赛制 |
|------|---------|-----------|----------|
| 得分方式 | 部分分 | 全有或全无 | 部分分 |
| 提交次数 | 有限 | 无限（AC 后不计） | 有限 |
| 实时排名 | 否 | **是** | 否/部分 |
| 罚时机制 | 无 | **有（20min/次）** | 无 |
| 主力赛事 | 蓝桥杯/CSP | **ICPC/CCPC** | 天梯赛/IOI |


## 主要赛事介绍

算法竞赛的赛事体系丰富多样，覆盖从入门到顶级的各个层次。以下为校队关注和参与的主要赛事概览，更详细的赛事信息可查阅 [AlgoWiki 赛事专区](https://www.algowiki.cn/competitions?tab=calendar)。

### XCPC 系列（核心赛事）

XCPC 是 ICPC 与 CCPC 的统称，代表国内大学生算法竞赛的最高水平，**是本队的核心参赛目标**。

**ICPC（国际大学生程序设计竞赛）**

| 项目 | 说明 |
|------|------|
| 组织方 | ICPC Foundation（2018 年前由 ACM 赞助） |
| 参赛资格 | 在校本科生、研究生，每校可派多支队伍 |
| 队伍组成 | 3 人一队，共用 1 台电脑 |
| 比赛时长 | 5 小时 |
| 题目数量 | 10-13 题 |
| 晋级路线 | 网络预选赛 → 亚洲区域赛（Regional） → EC Final（亚洲区决赛） → World Finals（全球总决赛） |
| 赛季时间 | 网络赛（8-9月）→ 区域赛（9-11月）→ EC Final（12-1月）→ World Finals（次年4-6月） |

**CCPC（中国大学生程序设计竞赛）**

| 项目 | 说明 |
|------|------|
| 组织方 | 中国高校计算机教育研究会 |
| 赛制 | 与 ICPC 完全一致（ICPC 赛制） |
| 晋级路线 | 网络预选赛 → 分站赛 → 总决赛（CCPC Final） |
| 赛季时间 | 与 ICPC 同期进行 |

**现场赛流程概览**

通常分为热身赛和正式赛两天：

> **比赛流程与规则详见**：[AlgoWiki 比赛介绍｜XCPC](https://www.algowiki.cn/wiki?category=xcpc-contests&article=23) 

| 时间 | 内容 |
|------|------|
| Day 1 下午 | 报到注册、领取参赛材料、熟悉场地 |
| Day 1 晚 | 热身赛（1-2 小时，熟悉环境和平台） |
| Day 2 上午 | 开幕式、入场、设备检查 |
| Day 2 中午-下午 | **正式赛（5 小时）** |
| Day 2 傍晚 | 封榜结束、滚榜、颁奖典礼 |

### 蓝桥杯（个人赛）

> **蓝桥杯详见**：[AlgoWiki比赛介绍｜蓝桥杯](https://www.algowiki.cn/wiki?category=xcpc-contests&article=25)

| 项目 | 说明 |
|------|------|
| 全称 | 蓝桥杯全国软件和信息技术专业人才大赛 |
| 组别 | A组（985/211 本科）、B组（普通本科）、C组（高职高专） |
| 赛制 | OI 赛制（部分分） |
| 时长 | 4 小时 |
| 形式 | 个人赛，机房现场赛 |
| 晋级路线 | 省赛 → 国赛 |
| 赛季 | 省赛（4 月）→ 国赛（6 月） |
| 报名费 | 约 300 元/人 |
| 特点 | 难度相对友好，适合作为新队员的练手，获奖可丰富简历 |

### 团体程序设计天梯赛（GPLT）

> **团体程序设计天梯赛详见**：[AlgoWiki比赛介绍｜团体程序设计天梯赛](https://www.algowiki.cn/wiki?category=xcpc-contests&article=26)


| 项目 | 说明 |
|------|------|
| 全称 | 中国高校计算机大赛——团体程序设计天梯赛 |
| 赛制 | IOI 赛制（部分分） |
| 队伍组成 | 10 人一队 |
| 时长 | 3 小时 |
| 形式 | 团体赛，各校独立机房或统一赛场 |
| 赛季 | 通常每年 4 月 |
| 特点 | 考察团队整体实力，10 人得分累加排名，注重代码能力、手速、知识覆盖广度 |

### 其他赛事速览

| 赛事 | 类型 | 赛制 | 说明 |
|------|------|------|------|
| CCF CSP 认证 | 个人认证 | OI | CCF 软件能力认证，每季度一次，可作为能力证明，对转专业、保研等有作用，具体需要参考对应政策 |
| 各省省赛 | 团队 | ICPC | 如 GDCPC（广东）、HNCPC（湖南）等，省级选拔赛事 |
